# GOA 카드 게임

Socket.IO를 사용하는 2인 온라인 카드 게임입니다. Render에 배포하면 빠른 매치와 방 코드 대전을 바로 사용할 수 있습니다.

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:10000`을 엽니다. 온라인 대전은 3장 이상의 덱이 필요합니다.

## Render 배포

1. 이 폴더를 새 GitHub **repository**에 올립니다. (GitHub 라이브러리보다 저장소가 맞는 표현입니다.)
2. Render에서 **New → Blueprint**를 선택하고 GitHub 저장소를 연결합니다.
3. `render.yaml`을 인식하면 서비스가 생성됩니다. 생성되지 않으면 Node Web Service로 만들고 build command는 `npm install`, start command는 `npm start`를 사용합니다.
4. Render가 준 주소로 접속해 두 브라우저에서 `온라인 멀티플레이 → 빠른 매치` 또는 방 코드 대전을 실행합니다.

`/health`는 Render의 상태 확인용 주소이고, `/api/game-config`는 현재 밸런스 규칙을 제공합니다.

## 카드와 밸런스 패치

- 카드 능력치와 효과: `cards.json`
- 덱 제한, 초기 규칙, 밸런스 버전: `game-config.json`
- 서버에서 허용하는 덱 검증과 온라인 방 상태: `server.js`

수치 조정이나 카드 추가는 우선 `cards.json`과 `game-config.json`에서 처리합니다. 새로운 `skills[].type`이 필요할 때만 `game.js`에 효과 처리기를 추가합니다.

## 온라인 대전 동작

- 상대가 카드를 드로우하거나 아이템/스킬을 쓰고 몬스터를 배치하는 연출이 보입니다.
- 상대 손패는 카드 이름과 내용 없이 장수와 카드 뒷면만 표시됩니다.
- 빠른 매치와 방 코드 방 만들기를 지원합니다.
- 서버는 카드 ID, 덱 장수, 카드별 복사 제한을 확인합니다.

## 다음 확장 우선순위

현재는 카드 효과 판정 일부가 브라우저에서 이루어집니다. 랭크전·보상·상점처럼 경쟁성과 공정성이 중요한 기능을 공개하기 전에는, 모든 드로우·피해·동전·승패 판정을 `server.js`의 방별 게임 상태로 옮기고 로그인/영속 데이터베이스를 붙이는 것이 다음 단계입니다.
